# STC90C51RC 模型

## 1. 文件

| 文件 | 作用 |
|---|---|
| `models/stc90c51.json` | STC90C51RC 芯片模型 |
| `build/libmcus_isa_8051.so` | 8051 ISA 动态库 |
| `tests/test_stc90c51.cpp` | 模型加载、P1 输出和引脚同步测试 |

模型基于 STC90C51RC：4KB Flash、512B SRAM（256B iRAM + 256B xRAM）、3 个定时器、
1 个增强 UART、4 个外部中断、P0–P4 端口。

## 2. 运行

```bash
./build/mcus \
  --isa ./build/libmcus_isa_8051.so \
  --model models/stc90c51.json \
  --firmware firmware.hex \
  --config config/example.toml
```

支持 `.bin` 和 Intel HEX；固件加载到 `code` 空间起始地址 `0x0000`。

## 3. 地址空间

| 区域 | 地址 | 大小 | 说明 |
|---|---:|---:|---|
| `code` | `0x0000` | 4KB | 只读程序空间 |
| `iram` | `0x0000` | 256B | 内部 RAM，栈从 `0x07` 开始 |
| `sfr` | `0x80` | 128B | 特殊功能寄存器 |
| `xram` | `0x0000` | 256B | 片上扩展 RAM，地址回绕 `0xFF` |

## 4. 外设

- **P0/P1/P2/P3/P4**：端口寄存器映射到 `PinState`；P1.0/P1.1 为 T2/T2EX，P3.0/P3.1 为
  RXD/TXD，P3.2/P3.3 为 INT0/INT1，P4.2/P4.3 为 INT3/INT2。
- **Timer0/1**：`TL0/TH0`、`TL1/TH1`，`TCON` 控制启停和溢出标志。
- **Timer2**：`T2CON/T2MOD/TL2/TH2/RCAP2L/RCAP2H`，溢出重载并触发中断。
- **UART0**：`SCON/SBUF`，TX/RX 通过 `BusEvent(UartTx/UartRx)` 与外部程序交互。
- **中断**：INT0、Timer0、INT1、Timer1、UART0、Timer2、INT2、INT3；IE 为全局/外设使能，
  IP/IPH 保存优先级寄存器。
- **STC 扩展寄存器**：`AUXR/AUXR1/IPH/SADDR/SADEN/XICON/WDT_CONTR/ISP_*`、`P4`。

## 5. 限制

- Timer2 的向上/向下计数、可编程时钟输出未建模，只按 16 位向上重载计数。
- WDT 和 ISP/IAP 目前只有寄存器，没有看门狗溢出和 Flash 编程引擎。
- STC 的 6T/12T 双速模式未建模，`cycles_per_instruction` 固定为 1。
- INT0/INT1/INT2/INT3 的外部引脚边沿不会自动置位；需要外部程序写挂起位/中断位图，或后续补 EXTI 映射。
- 4 级中断优先级由 `IP/IPH` 寄存器保存，但模型使用静态 `priority`，运行时改 IP 不改变仲裁顺序。
- EEPROM、PCA（若型号带）未建模。
